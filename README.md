# 🚀 HTML & CSS Practice Projects Repository

A complete collection of beginner-friendly HTML and CSS practice projects built while learning frontend web development.

This repository contains multiple HTML pages, CSS styling exercises, image-based UI designs, and mini frontend projects including an Amazon homepage clone.

It is designed to strengthen web development fundamentals and improve UI building skills.

---

## 📚 Topics Covered

### 🔹 HTML Basics
- HTML Structure
- Headings & Paragraphs
- Links & Images
- Lists & Tables
- Forms & Inputs

### 🔹 CSS Basics
- Colors & Backgrounds
- Margins & Padding
- Borders & Box Model
- Fonts & Typography
- Positioning
- Flexbox Basics
- Hover Effects

### 🔹 Web Page Designs
- Multiple Styled Web Pages
- Image-Based Layouts
- Responsive Design Practice
- UI Styling Exercises

### 🔹 Mini Frontend Projects
- Amazon Homepage Clone
- Styled Landing Pages
- Practice UI Components
